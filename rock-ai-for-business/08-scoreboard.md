# Phase 8: Rock Scoreboard

Rock statement: launch AI for Business Raleigh, hold 3 events (Aug, Sep, Oct 2026), reach 25+ attendees by event #3, track attribution from event #1, and close 1 paid services client sourced from the event by October 31, 2026.

Review cadence: leading metrics logged every Friday; lagging metrics logged T+2 days after each event. One Notion page, one table, updated by Danny.

## Weekly leading metrics (log every Friday)

| Metric | Weekly target |
|---|---|
| New Luma registrations | 8+ in the 3 weeks before an event |
| Total confirmed for next event | see milestones below |
| Personal invite DMs sent | 10 |
| Facebook group posts published | 2 (per calendar) |
| Helpful FB group comments (non-promo) | 5 |
| LinkedIn posts about the event | 1+ |

## Monthly lagging metrics (log T+2 after each event)

| Metric | Definition |
|---|---|
| Attendees | Checked in on Luma, not registered |
| HOT leads, by service map | Assessment / Free review / Workshop / Build (from Phase 4 Notion table) |
| Free review calls booked | Attributed to event via source tag |
| Assessments sold ($999) | Paid, attributed |
| Workshops booked ($750+) | Paid, attributed |
| Newsletter subscribers attributed | Joined via event links |
| Client closed (Rock measurable) | Y/N: any paid engagement (assessment, workshop, or build) from an event-sourced lead |
| **Positioning row** | Inbound speaking invitations + press/podcast asks + partnership approaches generated by the event. Target: 1 by Sep 30, 3+ cumulative by Oct 31 |

| | Event #1 (Aug 26) | Event #2 (Sep 23) | Event #3 (Oct 28) |
|---|---|---|---|

## Tripwires (act, do not admire)

- Registrations under 15 at T-1 week: shift all remaining promo hours to personal DMs and direct asks; they convert 5x better than posts.
- Zero HOT leads at an event: the demo was too abstract; next month's demo must show dollars saved for a named business type.
- No assessment sold by Sep 30: add a meetup-only incentive (e.g. free review credited toward the $999 assessment) announced in the event #3 CTA.
- Venue friction of any kind: activate the Phase 1 backup immediately; never let venue uncertainty within 2 weeks of an event.
